# Remote Patient Monitoring System

**Status:** Ongoing  

A camera-based system to detect and classify patient activities (sitting, walking, lying, falling) and send real-time alerts via Twilio and Email. This project helps caregivers monitor patients remotely and respond quickly to abnormal activities.

## Features (Planned)
- Activity detection using deep learning and computer vision
- Real-time alert notifications for abnormal activities
- User-friendly interface

## Tools & Technologies (Planned)
- Python
- OpenCV
- Webcam
- Laptop device
- MediaPipe
- Twilio API
- Email API
- TensorFlow

## Project Goals
- Implement activity recognition for patients
- Reduce caregiver workload with automated monitoring
- Generate alerts for falls or unusual inactivity

## Timeline
- Jan 2025 – Design and planning
- Feb 2025 – Model development
- Mar 2025 – Integration and testing
